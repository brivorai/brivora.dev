Brivora is open source under AGPL v3. We welcome contributions.

## How to contribute

1. Fork the repository
2. Create a feature branch
3. Write tests for your changes
4. Submit a pull request

## Governance pack contributions

We especially welcome new governance packs for regulations not yet covered. See [Create Custom Governance Packs](/verify/custom-packs/) for the pack format.

## Code of conduct

Be direct. Be honest. Ship code. No corporate speak.

## Development setup

```bash
git clone https://github.com/brivorai/brivora.git
cd brivora
npm install
npm test
```

## Questions

Open a GitHub Discussion or join our [Discord](https://discord.gg/brivora).
